About

Lunix

I'm Lunix, an 18-year-old trans software development student from the Netherlands. I got into coding almost by accident. A friend pushed me to try web development, and it hooked me almost immediately. I spent a while bouncing between web dev and game dev before eventually dropping the latter and gravitating toward something else entirely: building small terminal applications. There's something I like about the constraint of a command line, no framework to lean on, just you and the problem.

Right now I'm splitting my time between school and personal projects. At ROC van Twente I'm learning Razor Pages. Outside of class I'm building ldcss, a CSS framework built to be structured but not rigid, ldmp, a terminal-based music player, and working on client work like NerineZorg alongside my own portfolio.

I care about clean design and dependable code in equal measure. I'd rather ship something a little smaller that actually holds together than something flashy that doesn't. That's shown up in most of what I build: a bit of structure, with enough give in it to stay fun to work in.
